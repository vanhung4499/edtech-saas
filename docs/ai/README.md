# AI Working Guide

This folder contains the practical rules that AI agents should follow when working in this repository.

Read order:

1. `project-brief.md`
2. `module-map.md`
3. `backend-rules.md`
4. `frontend-rules.md`
5. `task-checklist.md`

Templates live in `templates/`.

These files are intentionally short. The goal is to reduce guessing during AI-assisted development.
